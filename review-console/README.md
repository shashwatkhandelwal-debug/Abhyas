# Review Console (`review-console/`)

Web console for expert FLN coaches to:
1. Review and approve newly generated teaching move cards and rubrics (requires 2 coach approvals before publishing).
2. Triage the **Expert Review Queue**:
   - Spoken rehearsal scores with model confidence < 0.60.
   - "Explain it back" submissions with ambiguous coverage.
   - Unanswered teacher classroom management questions routed for ARP escalation.
